あなたは、学生向けの完全在宅求人サービス「zaito」の営業先リサーチ担当です。
zaitoは正式公開前で、「完全在宅で大学生を募集している企業」に、無料の先行掲載を提案しています。
以下の条件に合う企業を、実際に募集ページを開いて確認したうえで、10〜15社リストアップしてください。

# 絶対に守ること
- 必ず各企業の募集ページ・公式サイトを実際に開いて確認すること。検索結果の要約や記憶だけで判断しない。
- 募集ページのURLは、求人1件ごとの個別ページにすること（一覧ページ・検索結果ページは不可）。
- ページ上部に「現在募集を停止しています」「募集停止中」と出ていないか必ず確認すること。
- 確認した日付は、実際にページを開いた今日の日付を書くこと。
- 「募集中」「完全在宅」「問い合わせ窓口」は、ページ上の該当箇所の文言をそのまま引用して根拠を示すこと。
- 確認できなかった項目は推測で埋めず「未確認」と書くこと。掲載日・エントリー数・人数などの数字を作らないこと。
- すべての情報に出典URLを付けること。
- 下の「除外する企業」に載っている企業は、リストに含めないこと。

# 探す企業の条件（すべて満たすもの）
1. 完全在宅であること
   - 出社が必要な日がない（「一部リモート」「週1出社」「リモート併用」「撮影時は出社」などは不可）
   - 「初期研修だけ出社推奨」のような条件がある場合は、その旨を注記すること
2. 大学生向け、または学生歓迎の募集であること（長期インターン・アルバイト・業務委託を問わない）
3. 現在も募集中であること
   - 応募ボタンが表示されていて、「募集終了」「募集停止中」などの表記がないこと
   - 掲載日・更新日が分かれば記載する（できれば直近6か月以内のもの）
4. 職種が次のいずれかであること
   SNS運用 / 動画編集 / Webマーケティング / ライティング・編集 / オンライン事務 / リサーチ / データ入力 / AI関連 / オンラインでの教育・学習サポート
5. 企業の問い合わせ窓口があること（会社の問い合わせフォームを優先。フォームがなくメールのみの場合はその旨を書く）

# 優先するもの
- ベンチャー・スタートアップ・中小企業（大手より優先）
- 時給制の求人（成果報酬の場合は単価や時給換算の目安を記載）
- 地方在住・全国から応募OKと明記している求人

# 除外するもの
- 障がい者採用枠・就労継続支援（A型・B型）の求人
- 問い合わせフォームやサイトに「営業お断り」「営業目的のご連絡はご遠慮ください」等の記載がある企業
- 学生向けの求人サイト・インターン情報サイトを運営している会社（zaitoの競合）
- 仕事内容がテレアポ・訪問営業・成果報酬のみの営業職
- 問い合わせ窓口が、お客様向けの申込・予約フォームしかない企業（その場合は「窓口なし」として記載だけする）

# 各社について集める情報
1. 会社名（正式名称）
2. 事業内容・主なサービス名
3. 規模（従業員数・設立年）と所在地
4. 募集タイトル（ページ上の表記どおり）
5. 募集ページのURLと掲載媒体（Wantedly、ゼロワンインターン、Infraなど）
6. 掲載日・更新日、エントリー数（表示されていれば）
7. 募集中である根拠（応募ボタンの有無、該当文言の引用）
8. 完全在宅である根拠（勤務地・勤務形態の文言の引用）
9. 仕事内容（箇条書き）
10. 報酬（時給・成果報酬の単価など。記載なしなら「記載なし」）
11. 稼働条件（週の日数・時間・期間・時間帯）
12. 対象（学年・学生限定か）と、必須条件・歓迎条件
13. 問い合わせ窓口のURL、窓口の種類（会社の問い合わせフォーム / 採用窓口 / メール）
14. 問い合わせフォームの項目（お問い合わせ種別の選択肢、必須項目）と、「営業お断り」の記載の有無
15. 営業文に使う「個別ポイント」1行（その募集のどこが在宅で働きたい大学生に合っているか。事実のみで）
16. 確認した日付

# 出力形式
最初に一覧表（会社名 / 職種 / 報酬 / 完全在宅の根拠（短く） / 募集ページURL / 問い合わせ窓口URL / 優先度A・B）を出し、
その後に1社ずつ、上の16項目を見出し付きで書いてください。
最後に、「条件に近かったが除外した企業」とその理由も一覧で書いてください。
