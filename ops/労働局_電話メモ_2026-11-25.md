# 労働局（特定募集情報等提供事業の届出）との電話 2026-11-25

運営者（〇〇）が電話で確認した内容。通知書と、6情報をまとめたリーフレット（1枚）が郵送で届く予定。

## 言われたこと
1. **苦情・相談の窓口（第6条）**：募集情報等提供事業者は、利用者（求職者・求人企業）からの苦情・相談を受け付けなければならない。サービスの中に、フォームや窓口など、どんな形でもよいので設けて対応すること。
2. **求人情報の「6情報」**：求人情報を出すときは、少なくとも次の6つを入れること。
   - 求人企業の名称（事業者名）
   - 所在地
   - 就業場所
   - 業務内容
   - 賃金
   - 連絡先
3. **個人情報**：サイバー攻撃・不正アクセスが増えているので、適切に管理すること。不要になった情報は、その都度消すこと。
4. **録画面接**：いまのままでよい。
5. **募集が終わった求人**：消したほうがよい（いつまでも載せない）。
6. **職業紹介にあたらないよう注意**すること。
7. 届出の記載と内容のまま進めてよい。

## zaito で対応すること（状況は会話とコミットで記録）
- [x] お問い合わせのページ（/contact/。苦情も受け付ける）を作り、フッター・メッセージ画面から案内する。受けた内容と対応は管理画面「お問い合わせ」に記録する。呼び名は「苦情」ではなく「お問い合わせ」（運営者の判断）。
- [ ] 直接掲載の求人：企業の所在地・連絡先を登録で集め、求人ページに6情報がそろうようにする。
- [ ] まとめ求人（他社の求人の紹介）：各社の所在地・連絡先を調べて足す。足せない求人は載せない。
- [x] 募集が終わった求人は、一覧からも詳細ページからも消す。
- [ ] 個人情報：自動では消さない（運営者の判断）。削除の依頼があれば、その都度消す。
- [ ] 職業紹介にあたらないかの点検（運営が学生を選んで企業にすすめない、メッセージを書き換えない、条件の交渉をしない など）。
