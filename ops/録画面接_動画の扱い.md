# 動画で答える応募：動画の扱い（2026-11-12 運営者が決定）

## 決めたこと
| 項目 | 決めたこと |
|---|---|
| 保存期間 | 応募の日から90日で、自動で消す |
| 企業ができること | zaitoの管理画面で再生するだけ。ダウンロードのボタンは出さない（画面の録画までは防げない） |
| 学生が応募を取り消したとき | その場で動画を消す。問い合わせで「消してほしい」と言われたときも同じ |
| 見られる人 | 応募先の企業と、zaitoの運営だけ（ログインが必要） |

## 作るときに守ること
- 動画は公開フォルダ（public_html）の外に置く。WordPressの uploads には置かない（URLを知っている人なら誰でも開けてしまうため）。
- 再生はPHPを通して渡し、そのたびに「応募先の企業か・運営か」を確かめる。
- iPhoneのSafariで再生できるように、動画を少しずつ渡す仕組み（HTTPの Range）に対応する。
- 録るときは、mp4で録れるブラウザではmp4を選ぶ（どの端末でも再生できるように）。サーバーで形式の変換はしない。
- 1問ずつ送る（1回5〜8MB。サーバーの上限は1回1GB、処理の時間は180秒）。
- 毎日の自動処理で、90日を過ぎた動画を消す。消したことは件数だけ記録する。
- エックスサーバーの自動バックアップに、消した動画も最大14日ほど残る。プライバシーポリシーには、このことも含めて書く。

## 容量の見積もり（2026-11-12 時点）
- サーバーの容量は500GBで、使っているのは0.52GB。
- 1人3問で約20MB。月に1,000人が応募して90日分たまっても約60GBなので、足りる。

## 公開の前にやること
- プライバシーポリシー（page-privacy.php）と利用規約に、動画の扱い（目的・見られる人・90日で消すこと・取り消したら消すこと・バックアップに最大14日ほど残ること）を書き足す。
- 録る画面で、学生に上の内容を見せてから録画を始める。
- 試験環境（https://staging.zaito-work.com/）で、iPhone・Android・パソコンで録って、企業の画面で再生できるかを確かめてから本番に出す。
