# ススメル UI/UX リニューアル設計（2026-10-26）

以下は初期リニューアル時の設計記録です。現在はセルフ版の新規販売・新規登録を停止し、料金は代行の3段階だけを掲載しています。報告書は結論と優先3項目から表示します。現行仕様はREADMEと `docs/launch-runbook.md` を参照してください。

追記（見やすさの改善）：トップはサービス内容・結果の見本・利用の流れ・料金を中心に整理。詳細な表・ランキング・相場比較はトップから外し、レポートや料金ページで確認する構成に変更。料金は全画面で3プランのカードを使い、スマホの共通ヘッダーには開閉できるナビゲーションを設けています。料金・作業範囲は変更していません。

参考：Linear・Peec AI・Plausible・Attio の実画面（PC 1440px／スマホ 390px で確認）と、依頼時に添付された Peec AI のダッシュボード画面。

## 参考サイトから取り入れる原則
| 参考 | 取り入れること |
|---|---|
| Linear | 二段の見出し（濃い主文＋グレーの補足）、少ないナビ、罫線で区切るセクション、装飾のない説明 |
| Peec AI | サイドバー＋上部の条件表示のダッシュボード、「業界ランキング」型の比較表（順位・名前・割合・前回）、言及の一覧 |
| Plausible | 指標の帯（ラベル・値・補足を横一列）、1本の折れ線グラフ、行の背景に割合の棒を敷いた表、カードを重ねない |
| Attio | アプリの窓枠でプロダクトを見せる、細い罫線と控えめな青、黒と白のボタン、整った表とフォーム |

## 共通のデザインシステム
- 色：背景 `#FFFFFF`、補助背景 `#F8FAFC`、文字 `#111827`、補助文字 `#4B5563`、罫線 `#E5E7EB`、アクセント `#2563EB`（1色のみ）。状態色（直す・直すとよい・OK）は記号と文字を必ず併記
- 書体：英数字 Inter、日本語 Noto Sans JP。数字は等幅数字（tabular-nums）
- 文字：本文16px、補足14px、ラベル12〜13px（常用しない）。見出しは 40〜48px／24〜28px／18〜20px の3段
- 角丸：6〜12px。影は窓枠のプロダクトプレビューだけ
- 部品：ボタン（主・副・文字）、指標の帯、比較表（行内の棒）、優先度ラベル、入力欄（ラベル・補足・エラー）、窓枠、セクション見出し（ラベル＋二段の見出し）

## ページ別

### トップ `/ai`
- 現在：見出し＋報告書の縮小版の2列、その下に「報告書でわかること」4段、事例、料金、濃い帯のCTA
- 問題：縮小版が小さく、製品の画面に見えない。4段の説明が長く、ページ全体が縦に長い。蛍光ペンの黄色が強調として多すぎる
- 参考との差：Plausible・Attio・Peec はファーストビュー直下に、実物大に近い製品画面を窓枠で置いている
- 修正後：左揃えの見出し・サブコピー・CTA2つ → 全幅の窓枠に**実際の報告書ダッシュボード（デモと明記）** → 3つの機能を「左に一言、右に実物の部品」で短く → 事例を数字の帯で → 進め方と料金を罫線の表で → 簡素なCTA

### サンプル報告書 `/ai/sample`
- 現在：縦1列の文書。最初に数字3つ、そのあと長い表とリストが続く
- 問題：どの数字が大事で、何を意味するかが分からない。診断項目が長い1列
- 修正後：Peec 型のダッシュボード（PCは左サイドバーで目次、スマホは上部の横スクロール目次）
  1. サービス名・計測日・データの説明
  2. 指標の帯（紹介率、比較候補の中の順位、自社サイトが引用された割合、サイト診断）＋紹介率の推移＋比較ランキング
  3. 最初に直すこと（優先度つき3件）
  4. 質問ごとの結果（自社の順位と、代わりに紹介されたサービス）
  5. 競合と引用元（行内の棒つき表）
  6. サイト診断の詳細（「AIが読めるか」「何のサービスか伝わるか」「情報の中身」「機械向けのデータ」に分類）
- ログイン後の実際の報告書も同じ部品で表示する

### 料金 `/ai/pricing`
- 現在：代行の3段階が同じ形の箱で並ぶ。セルフ版は文末のリンクだけ
- 問題：どれを選べばいいか、装飾（枠の色）でしか分からない
- 修正後：最初に「改善を任せたい／自分で計測したい」を選ぶ → 代行は比較表（料金・期間・内容・こんな方に）、セルフ版は小さな比較表と `/ai/tool` への導線。料金・期間・内容・税の表記は変えない

### 申し込み `/ai/apply`
- 現在：説明が長く、フォームの項目が1列に並ぶだけ。エラーはフォーム上部に1つ
- 修正後：上部で「無料で診断／トライアル」を切り替え（`?plan=trial` を維持）→ 項目を「診断するサービス」「ご連絡先」「任意」に分ける → 項目ごとにエラーを表示 → 送信後の流れを時系列で。スマホではフォームを先に

### セルフ版ツール `/ai/tool`
- 現在：料金表だけ
- 修正後：ツールの画面（計測結果）を見せ、使い方を3手順、できることを短く、料金表とCTA。トップと同じ説明は繰り返さない

### ログイン・新規登録・管理画面
- ログイン・登録は同じ形（左揃えの見出し、入力欄、主ボタン）にそろえる
- 管理画面は、色・書体・部品（ボタン・表・報告書）を新しいデザインシステムに合わせる。認証・課金・権限・計測の処理は変えない
