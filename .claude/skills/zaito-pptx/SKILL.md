# zaitoのデザインでプレゼン資料を作る

このスキルは、zaitoのデザインだけを決める**ラッパースキル**である。
.pptxの作り方（作成・編集・QA）は汎用の `pptx` スキルに任せ、色・フォント・レイアウトだけをzaitoの決まりで上書きする。

---

## 必須の手順（この順番で行う）

### Step 1: 汎用のpptxスキルを読み込む

最初に汎用の `pptx` スキルを読み込む。環境によって次のどちらかを使う。

- Skillツールで `anthropic-skills:pptx` を呼ぶ
- `.claude/skills/pptx/SKILL.md` があれば、それを読む

汎用スキルの手順（作成の流れ、QA、画像の変換など）にはすべて従う。
ただし、**色・フォント・デザインの指示は、このスキルの決まりを常に優先する**。
汎用スキルにある「表紙を暗い背景にする」などの明暗の指示は**使わない**。zaitoの資料は全スライド白い背景で統一する。

### Step 2: zaitoのデザインを当てる

下の「デザインの決まり」に従って作る。

### Step 3: QAをする

汎用pptxスキルのQA手順（テキストの確認と、画像にして見た目を確認する）に従う。加えて、下の「仕上げのチェックリスト」を必ず確認する。

---

## 🔴 いちばん大事な決まり

これまでの資料づくりで、運営者が「ダサい」「見づらい」と指摘した点から決めたルールである。必ず守る。

1. **全スライド白い背景（`#FFFFFF`）で統一する。** 紺や黒の背景のスライドは作らない（表紙・まとめ・強調したいスライドも含めて）。
2. **色のついた箱やカードを不用意に使わない。** 内容は、細い区切り線（`#E6E9F0`、0.75pt程度）と文字の大きさ・太さで整理する。塗りつぶした四角でグループを作らない。
3. **色は紺と青の2色だけ。** 紺 `#0B1530` が文字の基本、青 `#3D5AFE` は番号・見出しラベル・1か所の強調だけに使う。**黄色は使わない。** オレンジ・緑・赤などの追加のアクセント色も使わない。
4. **表紙はシンプルに。** ロゴ、タイトル、一文のサブタイトル、名前と日付だけ。画面イメージやカードなどの飾りを足さない。
5. **余白を残しすぎない、詰め込みすぎない。** 項目が少ないスライド（目次など）は、項目の行の間隔を広げてスライドの高さを使う。下半分が空いたままにしない。
6. **日本語の改行は区切りのいいところで。** 文の途中や単語の途中で折り返さないよう、「、」や文の終わりで改行（`breakLine`）を入れ、1行の長さを枠の幅に収める。

## デザインの決まり

### 色

| 用途 | 色 | HEX |
|---|---|---|
| タイトル・見出し・大事な本文 | 紺 | `#0B1530` |
| アクセント（番号、見出しラベル、強調1か所） | 青 | `#3D5AFE` |
| 本文 | グレー（濃） | `#3A4563` |
| 補足・ラベル | グレー（中） | `#4A5573` |
| 注記・ページ番号・出典 | グレー（薄） | `#6B7590` |
| 区切り線 | 薄いグレー | `#E6E9F0` |
| 背景 | 白 | `#FFFFFF` |

- `#6B7590` より薄いグレーを文字に使わない（読みにくくなるため）。
- 白い文字（`#FFFFFF`）は使わない。白い背景で統一しているため、白い文字が必要になる場面はない。

### フォント

| 用途 | フォント |
|---|---|
| 見出し・本文（日本語） | Noto Sans JP |
| ロゴ・番号・英字のラベル・大きな数字 | Outfit（なければ Arial） |

`fontFace` には Noto Sans JP を指定する。相手のPCにフォントがない場合に備え、資料を渡すときはPDFでも書き出すことをすすめる。

### 文字の大きさ（スライドサイズ 16:9、10" × 5.625"）

| 要素 | サイズ | 色 |
|---|---|---|
| 表紙タイトル | 32-40pt 太字 | `#0B1530` |
| 表紙サブタイトル | 14-16pt | `#3A4563` |
| 見出しラベル（例：「01　zaitoの現状」） | 11-12pt 太字 | `#3D5AFE` |
| スライドのタイトル | 22-26pt 太字 | `#0B1530` |
| 行の項目名（左側） | 13-15pt 太字 | `#0B1530` |
| 本文 | 12-14pt | `#3A4563` |
| 大きな数字 | 40-54pt 太字（Outfit） | `#0B1530`（1つだけ `#3D5AFE`） |
| 数字の説明 | 11-12pt | `#4A5573` |
| ページ番号・出典 | 9-10pt | `#6B7590` |

### ロゴ

- ロゴは画像を使わず、**テキストで作る**：「za」「i」「to」の3つに分け、「i」だけ青 `#3D5AFE`、ほかは紺 `#0B1530`。フォントは Outfit の太字。
- ロゴを置くのは**表紙と最後のスライドだけ**。本文のスライドには置かない。ロゴのまわりには、ロゴの高さの半分以上の余白を取る。

```javascript
// ロゴ（表紙・最後のスライドのみ）
slide.addText([
  { text: "za", options: { color: "0B1530" } },
  { text: "i",  options: { color: "3D5AFE" } },
  { text: "to", options: { color: "0B1530" } },
], { x: 0.7, y: 0.6, w: 3, h: 0.6, fontFace: "Outfit", fontSize: 30, bold: true, margin: 0 });
```

### 余白と配置

- 左右の余白：0.7" 以上（x ≥ 0.7、x + w ≤ 9.3）
- 上の余白：0.6" 以上、下の余白：0.5" 以上
- 見出しラベルとタイトルは、**本文のスライドすべてで同じ位置**に置く（めくっても見出しが動かないように）。
- ページ番号は左下に小さく「zaito　3」のように置く。表紙には置かない。

## よく使うレイアウト

### 1. 表紙
上にロゴ、中央にタイトルとサブタイトル（1文）、下に「zaito 代表　〇〇 ｜ 日付」。それ以外は置かない。

### 2. 目次
左上に見出しラベル「AGENDA」とタイトル「本日の流れ」。その下に、番号（青、Outfit）と項目名の行を並べ、行の間に区切り線を引く。行の高さを広げて、スライドの下まで使う。時間の目安は書かない。

### 3. 「項目名＋説明」の行（いちばん使う形）
左に項目名（太字、幅2.6"程度）、右に説明文。行と行の間に区切り線を引く。カードや箱は使わない。

```javascript
// 1行分。y を行の高さずつ下げて繰り返す
slide.addShape(pres.shapes.LINE, { x: 0.7, y: rowY, w: 8.6, h: 0, line: { color: "E6E9F0", width: 0.75 } });
slide.addText("収益の柱", { x: 0.7, y: rowY + 0.12, w: 2.6, h: 0.5, fontFace: "Noto Sans JP", fontSize: 14, bold: true, color: "0B1530", margin: 0 });
slide.addText("企業の求人をzaitoに直接掲載してもらい、料金をいただく", { x: 3.5, y: rowY + 0.12, w: 5.8, h: 0.5, fontFace: "Noto Sans JP", fontSize: 13, color: "3A4563", margin: 0 });
```

### 4. 大きな数字を3つ並べる
3列に分け、それぞれの上に区切り線、その下に大きな数字（Outfit）と短い説明。強調したい数字1つだけを青にする。

### 5. 3列の比較・要素
3列に分け、上に区切り線、見出し（太字）、2〜4行の説明。強調したい列だけ、上の線を青（2pt）にする。

### 6. 言い切りのスライド
白い背景のまま、大きなタイトル（32-36pt）と2行ほどの説明だけ。背景を暗くして強調しない。

### 7. 最後のスライド
タイトル（例：「zaitoを、一緒に作っていきませんか」）と、次のステップを3列で。下に「zaito 代表　〇〇 ｜ info@zaito-work.com ｜ zaito-work.com」。

## 文章の決まり

- 日本語で作る。
- 文はです・ます調か、体言止めに統一する（1つの資料の中で混ぜない）。
- 絵文字、文末のコロン、ダッシュ（——）は使わない。
- まだ決まっていない数字は `[__]` のように空欄にし、作ったあとで運営者に伝える。数字やデータを作り話で埋めない。
- 運営者の本名は、運営者が資料に入れるよう頼んだときだけ入れる。

- [ ] 塗りつぶした箱やカードを使っていないか？ 区切り線と文字だけで整理できているか？
- [ ] 使っている色は紺 `#0B1530`、青 `#3D5AFE`、グレー、区切り線の色だけか？ 黄色やほかのアクセント色はないか？
- [ ] 白い文字を使っていないか？
- [ ] 表紙に余計な要素（画面イメージ、カードなど）がないか？
- [ ] ロゴは表紙と最後のスライドだけか？「i」だけ青になっているか？
- [ ] 見出しラベルとタイトルの位置が、本文のスライドすべてでそろっているか？
- [ ] スライドの下半分が大きく空いていないか？ 逆に詰め込みすぎていないか？
- [ ] 日本語が単語の途中で折り返していないか？
- [ ] `[__]` などの空欄が残っている場合、運営者に伝えたか？
