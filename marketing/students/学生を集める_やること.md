# 学生を集める：やること（2026-10-13）

最初の目標は**学生の登録30人**。30人いれば、新着メールや「◯人が保存」の数字が意味を持ち、企業への営業でも「学生が◯人見ている」と言える。

## 準備できているもの
- サイトに「友達に教える」（LINE・X・リンクのコピー）を付けた。求人ページと、登録が終わった画面にある
  - 共有されたリンクには `utm_medium=share` が付くので、紹介で来た人数をGA4で数えられる
- 学生向けの投稿14本（画像＋X・Threads・Instagramの文面）→ `投稿文.md` と `img/`
- 大学のキャリアセンター・学生団体あての依頼文 → `../3_紹介してもらう先と依頼文.md` のA（学生団体には5番の「学生団体・サークル」あてに、Bの文を少し変えて使う）

## 運営者がやること（効く順）

### 1. 知り合いに直接送る（今日・15分）
最初の30人は、知り合いからがいちばん早い。広告で1人集めるのに数百円かかるが、友達へのLINEはタダで、開いてもらえる率も高い。
- 同じ大学の友達・サークル・ゼミの人に、**1人ずつ**送る（グループに一斉に流すより反応がいい）
- グループに流すときは、先に「バイト探してる人向けのサイト作ったから、ここに貼ってもいい？」と聞く

**個人に送る文**
```
いま、出社なしで働けるバイトとか長期インターンだけを集めたサイト作ってる！
「在宅OK」って書いてあっても研修で出社するやつ多いから、出社が本当にないか1件ずつ確かめて載せてる。
学生OKのが20件くらいあるから、バイト探してたら見てみて🙏
https://zaito-work.com/zaitaku/gakusei/?utm_source=line&utm_medium=friend
使いにくいとこあったら教えてほしい！
```

**サークル・ゼミのグループに送る文（許可をもらってから）**
```
【在宅バイト・インターン探してる人へ】
出社なしで働けるバイト・長期インターンだけを集めたサイトを作っています。
研修も含めて出社がないかを確かめて載せていて、学生OKの求人が20件ほどあります（時給1,200〜2,500円くらい）。
https://zaito-work.com/zaitaku/gakusei/?utm_source=line&utm_medium=group
登録は無料で、メールアドレスだけです。
```

**Instagramのストーリーズ（自分のアカウント）**
```
出社なしのバイトだけ集めたサイト作った
学生OK 20件くらい
→ リンク（https://zaito-work.com/zaitaku/gakusei/?utm_source=instagram&utm_medium=story）
```

### 2. 学生向けの投稿を毎日1本（1日5分）
- `投稿文.md` を上から順に、X・Threads・Instagramに投稿する（画像は `img/` のもの）
- 時間は20〜22時が目安。まとめ（R）と1件紹介を交互に
- 求人が増えたり減ったりしたら、Claudeに「学生向けの投稿を作り直して」と頼む

### 3. 大学のキャリアセンターに頼む（週に3校）
- まず自分の大学から。依頼文は `../3_紹介してもらう先と依頼文.md` のA
- 返事が来たら、Claudeに転送して返信文を作ってもらう

### 4. Meta広告（学生向けのC）は今のまま続ける
- 1週間たったら、GA4で `utm_campaign=ad_c` から来た人の登録数を見る
- 登録1人あたり500円を超えるなら止めて、そのお金を1〜3に回す

## 数え方
- 登録した人がどこから来たかは、管理画面「興味あり登録」のCSVの `utm_source`・`utm_medium` を見る
  - `line / friend`：友達に直接送った分
  - `line / group`：グループに送った分
  - `x・threads・instagram / social`：投稿から
  - `* / share`：サイトの「友達に教える」から（紹介の紹介）
- 1週間ごとに、どこから何人来たかを `学生を集める_記録.md` に書く（Claudeに頼めば集計する）

## やらないこと
- 知らない人へのDMや、関係ないグループへの書き込み（嫌われて逆効果）
- 「誰でも稼げる」「簡単に月◯万円」のような言い方
- 求人ページに書いていない報酬を書くこと
