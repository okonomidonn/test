# Meta広告（広告マネージャ）の出し方

Instagramに「投稿しない広告」を出すための手順。最初の7日間は需要の確認（1人いくらで登録が集まるか）が目的。
Metaの画面は時期によって言葉や場所が少し変わる。見つからないときはスクショを撮って確認する。

全体の流れ
1. 準備（1回だけ）：ビジネスポートフォリオ → Facebookページ → Instagramをつなぐ → 広告アカウントと支払い
2. ピクセル（任意だがおすすめ）：IDを作り、サイトに入れる
3. キャンペーンを1つ作る
4. その中に広告セットを3つ作る（A・B・C）
5. 公開して、1日目・7日目に結果を見る

---

## 1. 準備（1回だけ）

### 1-1. ビジネスポートフォリオを作る
1. PCで https://business.facebook.com を開く（普段のFacebookアカウントでログインしたまま）
2. 「アカウントを作成」→ ビジネス名 `zaito`、名前、ビジネス用メール（info@zaito-work.com）を入れる
3. メールに届く確認リンクを押す

### 1-2. Facebookページを作る（なければ）
1. ビジネスポートフォリオの「設定」→「アカウント」→「ページ」→「追加」→「新しいFacebookページを作成」
2. ページ名 `zaito`、カテゴリ `求人サイト`（なければ `ウェブサイト`）
3. 自己紹介：`出社なしの仕事だけを集めた求人サイト。運営が1件ずつ確認しています。`
4. ウェブサイト：`https://zaito-work.com/`
5. プロフィール画像はサイトのロゴ（wordpress-theme/zaito/lp/apple-touch-icon.png）

このページは広告を出すための「名義」。投稿はしなくてよい。

### 1-3. Instagramをつなぐ
1. 「設定」→「アカウント」→「Instagramアカウント」→「追加」
2. zaito_work でログインして許可する
3. zaito_work が「プロアカウント（ビジネスかクリエイター）」になっていない場合は、Instagramアプリの「設定」→「アカウントの種類とツール」で切り替える

### 1-4. 広告アカウントを作り、支払い方法を登録する
1. 「設定」→「アカウント」→「広告アカウント」→「追加」→「新しい広告アカウントを作成」
2. 名前 `zaito`、タイムゾーン **アジア/東京**、通貨 **日本円**（あとから変えられないので注意）
3. 自分に「フルコントロール」の権限をつける
4. 「支払い」→ クレジットカードかデビットカードを登録

注意：Facebookアカウントが停止から戻った当日は、支払い登録と広告の公開を避け、翌日以降にする。

---

## 2. ピクセル（おすすめ）

ピクセルを入れると「登録した人」の数が広告マネージャに出て、あとで「登録しそうな人」に寄せて配信できる。

1. https://business.facebook.com/events_manager を開く
2. 「データソースを接続」→「ウェブ」→ 名前 `zaito` →「作成」
3. 出てきた **ピクセルID（15〜16桁の数字）** を Claude に伝える
4. サイト側の設定（ページを見た・登録した、の記録）は Claude が入れて公開する

ピクセルがなくても、GA4と登録者CSVの utm_campaign で広告ごとの登録数は数えられる。

---

## 3. キャンペーンを作る

1. https://adsmanager.facebook.com を開き、左上の広告アカウントが `zaito` になっているか確認
2. 緑の「＋作成」
3. 目的：**トラフィック** →「次へ」
4. キャンペーン名：`zaito_test_2026-10`
5. 特別な広告カテゴリ：求人の広告なので、画面で「雇用」を選ぶよう求められたら選ぶ。選ぶと年齢を細かく指定できなくなるので、その場合はA〜Cを年齢ではなく画像と見せるページの違いで比べる
6. 「Advantage+ キャンペーン予算」は **オフ**（広告セットごとに予算を決めるため）

---

## 4. 広告セットを作る（まずA、そのあと複製してB・C）

### 4-1. 広告セットA
| 項目 | 設定 |
|---|---|
| 広告セット名 | `A_mikeiken_25-44` |
| コンバージョンの場所 | ウェブサイト |
| パフォーマンス目標 | **ランディングページビュー数を最大化**（ページまで開いた人を増やす。リンクのクリック数より質が良い） |
| 1日の予算 | **350円** |
| 開始日 | 明日の朝 |
| 終了日 | 開始から7日後 |
| オーディエンス | 地域：日本／年齢：25〜44歳／性別：すべて。詳細ターゲットは空欄のままでよい（Metaが自動で探す） |
| 配置 | 「手動配置」→ Instagram の **フィード・ストーリーズ・リール・発見タブ** だけにチェック。Facebook・Audience Network・Messengerは外す |

### 4-2. 広告A
| 項目 | 設定 |
|---|---|
| 広告名 | `A_phone` |
| Facebookページ | zaito |
| Instagramアカウント | **zaito_work**（ここを選ばないと別の名前で出る） |
| 形式 | シングル画像または動画 |
| 画像 | フィード用に `zaito_phone_A_square.png`、ストーリーズ・リール用に `zaito_phone_A_portrait.png`（「配置ごとに画像を変える」で設定） |
| メインテキスト | 下の「広告文」 |
| 見出し | 下の「広告文」 |
| ウェブサイトのURL | `https://zaito-work.com/zaitaku/mikeiken/?utm_source=meta&utm_medium=paid&utm_campaign=ad_a` |
| コールトゥアクション | 詳しくはこちら |
| 「Advantage+クリエイティブ」 | 文字や画像を勝手に変えられないよう、全部オフ |

### 4-3. B・Cを作る
広告セットAの「…」→「複製」→ 次だけ変える。

| | B | C |
|---|---|---|
| 広告セット名 | `B_jimu_25-44` | `C_gakusei_18-24` |
| 年齢 | 25〜44歳 | 18〜24歳 |
| 画像 | zaito_phone_B_square / portrait | zaito_phone_C_square / portrait |
| URL | `https://zaito-work.com/zaitaku/jimu/?utm_source=meta&utm_medium=paid&utm_campaign=ad_b` | `https://zaito-work.com/zaitaku/gakusei/?utm_source=meta&utm_medium=paid&utm_campaign=ad_c` |

### 広告文
報酬は求人ページに書いてある範囲だけ。「稼げる」「誰でも簡単」は使わない。

**A（未経験・ブランク）**
- メインテキスト：「在宅OK」なのに出社あり、はもうやめよう。zaitoは出社なしの求人だけを集めた求人サイトです。未経験・ブランクOKの求人も。運営が1件ずつ確認しています。登録無料。
- 見出し：未経験OK・出社なしの在宅求人

**B（事務）**
- メインテキスト：事務の経験を、出社なしで。経理サポート、営業事務、オンライン秘書など、出社がないことを運営が確認した求人だけを紹介しています。応募は各社の募集ページからそのまま。
- 見出し：通勤ゼロで働く、在宅の事務求人

**C（学生）**
- メインテキスト：通学時間をバイト時間に。SNS運用、マーケ、エンジニアなど、学生が応募できる出社なしの求人をまとめました。授業の合間に、自宅から。
- 見出し：学生OK・出社なしの在宅バイト

---

## 5. 公開と確認

1. 右下の「公開する」→ 審査（ふつう数時間〜1日）
2. 却下されたら、理由のスクショを撮って Claude に送る
3. **1日目**：3つとも「配信中」になっているか、表示回数が出ているかだけ見る。数字はまだ動かさない
4. **7日目**：広告マネージャで「列：パフォーマンスとクリック」にして、次の数字を広告セットごとにメモする
   - 消化金額／表示回数／リンクのクリック数／CTR（リンククリック率）／ランディングページビュー
   - あわせて、WordPress管理画面「興味あり登録」のCSVで utm_campaign（ad_a / ad_b / ad_c）ごとの登録数を数える
5. 判断（5_SNS広告テスト計画.md と同じ基準）
   - 登録1人あたり300円以下 → 続ける・予算を寄せる
   - 500円を超える → 止める
   - CTRが1%未満 → 画像と見出しを変える

7日間・3セット×350円で、合計は約7,350円。
