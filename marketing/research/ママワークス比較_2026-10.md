# ママワークスとzaitoの比較（2026-10-16 調べ）

| 項目 | ママワークス | zaito |
|---|---|---|
| 運営 | 株式会社アイドマ・ホールディングス（上場企業） | 個人運営 |
| 開始 | 2015年 | 2026年 |
| 規模 | 会員17万人・掲載1,162社（2020年1月の自社発表。最新値は非公開） | 求人71件・登録はごく少数 |
| 対象 | 子育て中の母親が中心（未婚・男性も可） | 完全在宅で働きたい人全般（主婦・社会人・学生） |
| 在宅の扱い | 「在宅／出社」で絞り込み。在宅と出社ありが混在し、「完全在宅」の定義はない | 全件「研修・会議を含めて出社なし」を運営が確認（基準を /kijun/ で公開） |
| 契約の形 | 新着は業務委託がほとんど（時間単価1,200〜1,800円など） | アルバイト・インターンが中心。業務委託も一部 |
| 求人の出どころ | 企業が料金を払って掲載 | 運営が企業の採用ページやSNSから探して掲載（今は企業から料金をもらっていない） |
| 応募 | ママワークス上で応募（会員登録が必要） | 元の募集ページで応募（zaitoは取り次がない。応募ページへ進むには登録が必要） |
| 企業の料金 | 要問い合わせ（掲載初期費用型・成果報酬型。無料プランなし） | なし（収益化はこれから） |
| 安全面 | 自社の審査基準を通った企業のみ掲載 | 運営が募集ページを読んで確認 |
| おまけ | 会員向けの無料講座（求人ライター講座など） | 保存（しおり）、条件に合う新着のメール |
