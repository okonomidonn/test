# SNS広告の画像

2種類あります。
- `pivot/`：PIVOT風（マゼンタ〜紫〜青のグラデーション、斜めの紺の帯に白い極太文字、強調は黄色）。作り直しは `node make_ads_pivot.js`
- このフォルダ直下：紺色の落ち着いた版。作り直しは `node make_ads.js`

まずはPIVOT風を使い、反応が悪ければ紺の版と比べる。

- `_square` は1080×1080（フィード用）、`_story` は1080×1920（ストーリーズ・リール用。上下の約250pxはSNSの表示で隠れるので文字を置いていない）
- 求人カードは実際に掲載している求人の職種・報酬・条件。会社名は広告に出していない（掲載企業の了承を得ていないため）
- 載せた求人の募集が終わったら、その画像は使わない。作り直しはスクリプトで数分でできる

## ChatGPTで写真入りの版を作るとき

ChatGPTの画像生成は日本語の文字を正しく描けないことが多いので、**文字なしの背景写真だけ**をChatGPTで作り、文字はこちらで重ねる。作った画像を送ってもらえれば、上と同じ文字・カードを重ねた版を作る。

指示文（ChatGPTにそのまま貼る）：

A（主婦・子育て中）
> 日本の自宅のダイニングテーブルで、ノートパソコンで仕事をしている30代の女性の写真。朝の自然光、木のテーブルとマグカップ、背景は少しぼかす。画像の上半分は文字を載せるので、壁などの何もない余白にする。文字やロゴは入れない。正方形 1080×1080。写真のようにリアルに。

B（事務経験のある社会人）
> 日本の自宅の書斎で、ノートパソコンとノートを使って事務作業をしている30代の人の後ろ姿の写真。整理された机、観葉植物、落ち着いた昼の光。画像の上半分は文字を載せるので余白にする。文字やロゴは入れない。正方形 1080×1080。

C（学生）
> 日本の大学生の部屋で、20歳前後の学生がノートパソコンで作業している写真。本棚と窓、夕方のやわらかい光、カジュアルな服装。画像の上半分は文字を載せるので余白にする。文字やロゴは入れない。正方形 1080×1080。

注意：実在の人物や他社のロゴが写った画像は使わない。生成した写真であることを気にする人もいるので、まずは今の文字だけの版と比べて、反応が良い方を残す。

## phone/：スマホ画面の版（2026-10-08）
zaitoの実際の求人一覧（条件別ページ）をスマホの枠に入れ、右に短い見出しを置いた版。会社名はぼかしている。
- A：主婦・子育て中（/zaitaku/shakaijin/ の画面）「出社なしの在宅ワーク、探してみませんか？」
- B：事務経験のある方（/zaitaku/jimu/）「事務経験を活かして在宅で働く。」
- C：大学生・院生（/zaitaku/gakusei/）「在宅でできるインターン、探してみませんか？」
- `_square` は1080×1080、`_portrait` は1080×1350（Instagramのフィードで大きく表示される縦長）
- 画面の求人が変わったら `src/capture_screens.js` で撮り直し、`src/make_phone_ads.js` で作り直す。バッジの時給は画面の求人と食い違わないようにする
