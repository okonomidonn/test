## 投稿の順番と本文

投稿は 01 から順に。最新の投稿が一番上に来るので、**06 → 01 の順で上から並ぶ**ことになる（01の自己紹介が最初に投稿されたものとして残る）。1日1本、または最初に3本まとめて投稿してもよい。

```
「国立で焼き鳥がおいしい店は？」

### 04 書いてあるかどうかで差が出た

```
「国立駅近くで一人飲みにおすすめの店は？」
この質問をChatGPTに3回聞きました。

・公式サイトに「カウンターはお一人様にも」と書いてあるお店 → 3回中3回紹介
・同じくカウンターがあるのに、その一言がないお店 → 0回

もちろん理由はひとつではありませんが、大きな違いは「書いてあるかどうか」でした。

AIは、お店に行ったことがありません。
書いてあることしか知らないんです。

一人で来てほしい、デートで使ってほしい、少人数の飲み会に使ってほしい。
来てほしいお客さんがいるなら、それを言葉にして公式サイトやGoogleマップに書いておくのがおすすめです。
