## 2. 料金（2026-10-26 改定・税別）

**方針（2026-10-26 決定）**
- **Webサービスに絞る。飲食店向けはやらない**（作成済みの飲食店資料 geo/kunitachi は参考として残す）
- 最初の商品は **GEO診断・改善トライアル 49,800円**。料金は3段階だけを見せる
- 最初の目標は月商ではなく **有料顧客3社・公開できる事例1件・継続契約1社**（3か月以内）
- 最初に狙う業種：**求人・人材サービス**（zaitoの事例がそのまま使える）。次点で専門スクール・BtoB SaaS
- 売り方：「AIに好かれる施策」ではなく、**「生成AIで比較・検討している見込み客に、自社の情報が正しく届く状態をつくる」**

### 料金表（3段階）
| ステップ | 料金 | 内容 |
|---|---|---|
| 1. 無料チェック | 0円 | ツールで主な質問を計測し、公式サイトを自動診断して結果を送る。営業前の調査は1社15分以内 |
| 2. **GEO診断・改善トライアル** | **49,800円**（1回・30日間） | ChatGPT・Geminiで各10問を計測／主な競合2社と比較（紹介回数・引用ページ）／直す点を3つ特定／既存ページを1ページ改善（CMSで編集できる範囲）／30日後に同じ条件で再計測して報告 |
| 3. 継続支援 | 月98,000円〜 | 毎月の計測とレポート／ページの作成・書き換え 月4ページ〜／構造化データ・robots.txt・サイトマップの保守／月1回の打ち合わせ。最低3か月 |

- トライアルに含まないもの：新しいページの制作、外部媒体への掲載、大規模な実装
- トライアルの作業時間の上限：**6〜8時間**。超えるなら内容か価格を見直す
- 成果保証はしない。納品物は「現状の数字・直した内容・30日後の数字」
- 最初の3社には、**対策前後の計測、匿名での数字の掲載、インタビュー**に事前の同意をもらう（社名の公開は任意）
- 税の表示：おまかせ（法人向け）は税別、見積書に税込の合計を書く。ツール（個人も使う）は税込

### やめたこと・保留したこと
| 項目 | 扱い | 理由 |
|---|---|---|
| 飲食店向け（店舗サポート） | やめる | 単価が低く、作業が増えるほど負担が増える |
| 詳しい診断 98,000円 | トライアルに置き換え | 有料顧客0社の段階では売りにくい |
| 月8ページ 198,000円 | 実績が出るまで出さない | 外部での紹介集めまで含めると1人では回らない |
| 成果に応じた追加料金 | 保留 | GA4の計測では成果の切り分けが難しく、もめやすい |
| 年払いの割引 | 保留 | 継続の需要と原価が分かるまでは損になる |
| 無料モニター | やめる | 無料は「無料チェック」まで |
| llms.txtを売りにする | やめる | Googleの生成AI機能は使っていないと公表している。説明の順番は「AIが読めるか → 独自の情報とページの質 → 外部での評判 → 計測」 |

### ツール（AI検索チェック）の扱い
- 料金は据え置き（フリー0円／スターター月4,980円／プロ月14,800円・税込）
- 当面は、無料チェックとトライアルの計測・報告を効率化する**社内の道具**として使う。ツール単体の集客にはお金をかけない
- 原価：ChatGPTだけなら1回答約30円（スターター最大月1,800円＝売上の約36%）。**Geminiも使うと2倍**になるので、ツールの有料プランはChatGPTのみで計測する

### 原価と作業時間の目安
- 計測のAI利用料：トライアル1件で約1,200円（2つのAI×10問×2回）
- 作業時間：トライアル6〜8時間、継続支援（月4ページ）月10〜15時間
- 1人で回せる上限の目安：継続支援5〜6社。それ以上は外注か値上げ

## 3. 具体的な手順

### 90日の計画
| 時期 | やること | 目標 |
|---|---|---|
| 1〜2週目 | 準備（下のSTEP 0）。求人・人材サービス10社に話を聞く（売り込まない） | 集客の悩み・予算・AI検索への関心・決める人を知る |
| 3〜4週目 | 求人・人材に絞って30社に個別に連絡。無料チェックの結果を添える | 返信・商談の数を見る |
| 5〜8週目 | トライアル（49,800円）を販売・実施 | 有料1〜2社 |
| 9〜12週目 | 最初の結果を資料に反映し、営業先を最大100社まで広げる。継続支援を提案 | 有料3社・事例1件・継続1社 |

- 30社で反応がなければ、値下げの前に「営業文・業種・提案内容」が合っているかを見直す
- 30〜50社に連絡してトライアルが1件も売れなければ、「今すぐお金を払うほどの課題ではない」可能性を考える

### STEP 0：準備（1〜2週目）
1. **Vercelを Pro に切り替える**（Hobbyは商用不可）
2. **zaitoの数字を確かめ直す**（GA4）
   - ChatGPT経由でキーイベントを1回以上起こした人の数（ユーザー単位）
   - 応募ボタンのクリック数と、実際の応募完了数
   - 日別のChatGPT経由の流入と、施策をした日の対応
   - ChatGPT経由と、広告を除いた自然な流入（direct・自然検索・SNS）との比較
3. 事例資料（print/zaito_case_study.pdf）と料金表（print/web_price_list.pdf）に担当・連絡先を入れる
4. 営業先のリスト：求人・人材サービスで、次に当てはまる会社
   - Webで応募や問い合わせを集めている／1件の応募・問い合わせにお金の価値がある
   - GA4などで計測している／自社サイトを自由に更新できる
   - 月5万〜10万円ほどのマーケティングの試し予算がある
5. 連絡文の型：「〇〇（その会社に当てはまる質問）とChatGPTに聞いたところ、御社は紹介されず、△△が紹介されていました。無料で計測結果をお送りします」

### STEP 1：無料チェック（1社15分以内）
1. ツールに登録（カテゴリ・対象・強み・URL）→ 自動で質問を作って計測 → サイト診断
2. 「紹介された質問／されなかった質問」「代わりに紹介された競合」「直す点の上位3つ」を短く送る

### STEP 2：GEO診断・改善トライアル（49,800円・30日間・作業6〜8時間）
1. **ヒアリング（30分）**：サービスを一文で言うと？／見込み客はどんな言葉で探す？／競合は？／GA4を見せてもらえるか／サイトを誰が更新できるか
2. **計測（初回）**：ChatGPT・Geminiで各10問。質問・日時・モデル・回答全文を保存（あとで同じ条件で測り直すため）
3. **競合2社と比較**：紹介された回数、引用されたページ
4. **直す点を3つ特定**。優先順位は次の順
   1. AIが読めるか：robots.txtで OAI-SearchBot などを止めていないか、本文がHTMLの文字で書かれているか
   2. 独自の情報とページの質：一文の立ち位置、固有の情報（事例・機能・料金・対応範囲）が1件1ページになっているか、紹介されなかった質問の答えがあるか
   3. 外部での評判：比較記事・レビュー・業界メディアでの紹介
   4. 構造化データ、サイトマップ、Bing Webmaster Tools（llms.txtは必須ではない）
5. **既存ページを1ページ改善**（お客さんの承認を取ってから。変更前の内容を保存）
6. **30日後に同じ条件で再計測**し、「紹介された回数・引用されたページ・AI経由の流入・問い合わせ／応募」を分けて報告
7. 継続支援を提案（作業量を決めて見積もり）

### STEP 3：継続支援（月98,000円〜・最低3か月）
1. 月初：同じ質問で計測（前月との比較）
2. GA4でAI経由の流入・着地ページ・問い合わせ／応募を確認
3. 紹介されなかった質問・競合が引用された質問から、次に作るページを決める
4. 月4ページ（契約による）を作成・書き換え。変更履歴を残す
5. 1枚のレポート（数字＋来月やること3つ）と、月1回の打ち合わせ

## 4. 注意（お客様に必ず伝える）
- AIの回答は毎回変わる。紹介や流入の増加は約束しない
- 効果が数字に出るまで数週間〜数か月かかる
- 事例の数字は、自社サイト1件・28日間のもの
