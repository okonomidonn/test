## 3. 具体的な手順

### STEP 0：準備（今週）
1. 事例資料（print/zaito_case_study.pdf）に担当・連絡先を入れる
2. 営業先を30社リストにする。向いている会社：
   - 「自社だけが持っている情報」が多いサービス：求人・不動産・スクール・比較サイト・予約サイト・SaaS（機能や事例が多い）
   - 社員10〜100人くらいで、マーケ担当が1〜2人の会社
   - Google検索で大手に勝てていない新しいサービス
3. 連絡はXのDM、問い合わせフォーム、知人の紹介。文面は「自社の求人サイトでChatGPT経由が成果の半分になりました。御社も無料で計測します」

### STEP 1：無料診断（1社 約3時間）
1. **ヒアリング（30分）**：サービスを一文で言うと？／お客さんはどんな言葉で探す？／競合は？／GA4を見せてもらえるか
2. **質問を20個作る**：お客さんがAIに聞きそうな質問。大きい質問5個（「〇〇のおすすめサービスは？」）＋細かい質問15個（「〇〇で△△できるツールは？」「〇〇と△△の違いは？」）
3. **計測**：`geo/kunitachi/measure_api.py` と同じ方法で、ChatGPT・Geminiに聞いて、紹介されたか・何番目か・どのページが参考にされたかを記録
4. **サイトの点検**（チェックリスト）
   - 一文の立ち位置がトップ・会社概要・FAQで同じ言葉か
   - 固有の情報（事例・機能・料金・対応範囲）が1件1ページになっているか
   - 本文がHTMLに書かれているか（画像や後から読み込むプログラムだけになっていないか）
   - 構造化データ（Organization、SoftwareApplication／Product、FAQPage、パンくず）
   - robots.txtでAIの読み取りを拒否していないか（GPTBot、OAI-SearchBot、ChatGPT-User、PerplexityBot、Google-Extended）
   - llms.txtがあるか
   - 更新日・確認日が書いてあるか
   - Bing Webmaster Toolsに登録しているか（ChatGPTの検索はBingの情報も使うため）
5. **GA4**：参照元に chatgpt.com・perplexity.ai・gemini.google.com・copilot など、が含まれる流入の人数・着地ページ・キーイベント
6. **レポート**：「紹介された質問／されなかった質問」「AIが参考にしたページ（競合のどのページか）」「直す順番トップ5」

### STEP 2：初期整備（契約後2〜4週間）
1. **一文の立ち位置を決める**：「誰の・何を・他と何が違うか」。全ページで同じ言葉にする
2. **1件1ページ化の設計**：事例・機能・料金・連携先・対応業種・比較などを、それぞれ独立したページにする。ページの型（見出し・項目）をこちらで作る
3. **紹介されなかった質問に答えるページ**：診断で紹介されなかった質問ごとに、答えになるページを作るか、既存ページに書き足す
4. **構造化データ**：ページの種類に合わせたJSON-LDのひな形を納品
5. **llms.txt**：サイトの説明、主要ページの一覧を作って置いてもらう
6. **robots.txt・サイトマップ・Bing Webmaster Tools・IndexNow** の設定
7. **外部での言及**：比較記事・業界メディア・プレスリリース・note等で、同じ一文で紹介されるようにする（AIは外部の情報も参考にする）
8. **GA4にAI流入の画面を作る**：参照元が `chatgpt|openai|perplexity|gemini|copilot|claude` に当てはまるものを絞り込む比較・探索レポート

### STEP 3：月次運用
1. 月初：同じ質問で計測（前月との比較）
2. GA4でAI流入の人数・着地ページ・キーイベントを確認
3. 「紹介されなかった質問」「AIが競合のページを参考にした質問」から、次に作るページを決める
4. スタンダードはページ4つを作成・書き換え
5. 1枚のレポートを送る（数字＋来月やること3つ）

## 4. 注意（お客様に必ず伝える）
- AIの回答は毎回変わる。紹介や流入の増加は約束しない
- 効果が数字に出るまで数週間〜数か月かかる
- 事例の数字は、自社サイト1件・28日間のもの
