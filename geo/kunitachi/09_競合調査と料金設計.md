### わかったこと

1. **店舗向けは「月3万円前後＋6か月以上の縛り」が標準。** 当初の想定価格（月29,800円）は LOCALGOAT とほぼ同額。
2. **同額で比べると機能では負ける。** LOCALGOAT は週1回の自動計測と110媒体への配信があり、個人の手作業では対抗しにくい。
3. **「買い切り」の店舗向けAI検索対策は、今回の調査では見当たらなかった。** スポットは企業向けの15〜30万円クラスのみ。
4. **成果報酬型はほぼ存在しない**（AIの回答が変わりやすく、効果の測り方が確立していないため）。

## 2. サブスクは必要か

**必須ではない。** 改善作業の大半は1回で終わる。

| 作業 | 1回で済む | 継続が必要 |
|---|---|---|
| 営業情報の統一（定休日・時間・席数） | ○ | 変更があったときだけ |
| Googleマップの整備 | ○ | 写真・投稿の追加は任意 |
| 公式サイトのFAQ・おすすめ・メニュー文章化 | ○ | 季節メニューの更新は任意 |
| 構造化データ | ○ | — |
| AIでの推薦状況の測定 | — | ○（効果確認と変化の把握） |
| 口コミ返信 | — | ○（店主自身でも可） |

継続の価値があるのは「測定」と「情報の鮮度維持」だけで、どちらも月3万円の価値を説明するのは難しい。飲食店側の「数か月でいいのでは」は正しい感覚。

## 3. 競合（特にLOCALGOAT）とどう戦うか

| LOCALGOATの強み | こちらの考え方 |
|---|---|
| 全部入りで月29,800円（税込）、MEO業者の相場より安い | 機能・価格の総合力では勝負しない |
| 週1回のAI自動計測、毎日の順位監視 | 測定は月1回で十分な精度。結果を「次に何を書くか」に変えて渡す |
| 110以上の媒体への一括配信 | 個人店で実際に見られているのは数か所（Google・食べログ・Apple・Bing・Instagram等）。そこを手で確実にそろえる |
| 口コミのAI返信、Instagram連携、ダッシュボード | 店主が管理画面を使う前提。使いこなせない個人店には「代わりにやる人」が必要 |
| 最低6か月契約 | **縛りなし** |

今回の測定で、ChatGPTの推薦を最も左右していたのは**店の公式サイトの文章**だった（08）。店主から話を聞いて文章を書く部分は自動化しにくく、ここが勝ち筋。

## 4. 確定した料金方針

効果の大部分は最初の整備で出し、その後は安い月額で「代わりに更新する人」になる。

| メニュー | 内容 | 料金（税別） |
|---|---|---|
| **初期整備パック** | 営業情報を主要媒体でそろえる、Googleマップ整備、公式サイトの「おすすめ」「よくある質問」「こだわり」・文字のメニュー掲載、構造化データ、1か月後の再測定レポート | **39,800円**（1回のみ） |
| **月額サポート ライト** | 毎月の簡易AI測定と1枚レポート、営業時間・メニュー変更の代行（月2回まで）、季節のお知らせ掲載（月1回） | **月4,980円・縛りなし** |
| **月額サポート スタンダード** | ライトの内容＋詳しいAI測定と競合比較、お知らせ掲載（月2回）、口コミ返信の文案 | **月9,800円・縛りなし** |
| **無料モニター（先着10店）** | 初期整備パック＋スタンダード3か月分 | **0円**（自動で有料にならない） |

- 原価：測定のAPI代はライト月約500〜800円（簡易測定）、スタンダード月約1,400円（ChatGPTのみ・45回答、08の実績）
- 「月5,000円以下」は飲食店にとって心理的に軽い。ライトは作業に上限を設けて時給を守る（1店月30〜45分）。利益の柱は初期整備パック
- 半年の総額比較：LOCALGOAT 約18万円（29,800円×6か月）に対し、こちらはライトなら 39,800円＋4,980円×5か月＝64,700円（税別）＝**税込 約7.1万円**（スタンダードなら税込 約9.8万円）
- 売上の目安：ライト40店＋スタンダード10店で月約30万円。これに新規の初期整備パック分が加わる
- 無料モニターでは「整備直後・1か月後・3か月後」の推薦率を測り、**買い切りでも効果が残るのか、継続が必要なのか**を自分のデータで確かめる
