# 07 営業資料一式（串と〆シ エソラ）

## 0. 営業前チェックリスト

- [ ] Googleマップ・食べログ・Instagramを目視確認し、[01の確認シート](./01_店舗調査_一次情報.md#営業前の目視確認シート)を埋める
- [ ] 診断レポートの「連絡先」を記入し、A4で2部印刷（[診断レポート](./06_無料GEO診断レポート_エソラ.md)）
- [ ] スマホで、ChatGPTに「国立で焼き鳥がおいしいお店は？」と質問した画面を用意（その日の結果をそのまま見せる。エソラが出ても出なくても使える）
- [ ] 名刺／連絡先カード
- [ ] 訪問は **17:00の開店直前（16:30〜16:50）を避け**、営業中の混雑も避ける。まずは電話かInstagram DMで10分の時間をもらうのが無難。来店して食事し、会計時に一言添えるのも可

## 1. 最初の接触（Instagram DM／電話／会計時）

**Instagram DM 文面**

> 突然のご連絡失礼いたします。国立で飲食店さま向けに「AI検索」の調査をしている〇〇と申します。
> 最近ChatGPTなどのAIで「国立で焼き鳥がおいしい店は？」と調べる方が増えており、国立駅周辺の居酒屋さんがAIでどう紹介されているかを調べています。
> エソラさんは「一人飲み」の質問で1番目に紹介されていた一方、「地元野菜」「デート」などの質問では名前が挙がっていませんでした。また、定休日がサイトによって「日曜」「不定休」と違って掲載されている点も見つかりました。
> 調査結果をA4数枚の無料レポートにまとめましたので、10分ほどお時間をいただけましたらお渡しして説明いたします。営業時間外のご都合のよい時間を教えていただけますと幸いです。

**電話・対面での一言（30秒）**

> 国立の飲食店さんがChatGPTみたいなAIでどう紹介されているかを調べている者です。エソラさんについて無料で診断したら、定休日の情報が食い違っているところなど、いくつか直したほうがいい点が見つかりました。レポートをお渡しして10分だけ説明させていただけませんか。売り込みではなく、まずは結果をお伝えしたいです。

## 2. 診断レポート説明の流れ（10〜15分）

1. **（1分）** AIで店を探す人が増えている話。スマホでその場でChatGPTに質問して見せる
2. **（3分）** 結果：「一人飲み1位、焼き鳥3位。でも国立野菜・〆・デートでは0回」
3. **（4分）** 課題：定休日の不一致 → 「日曜にAIが『営業中』と案内する可能性」。メニューがAIに見えていない。店名の読み
4. **（2分）** 今すぐできる無料の3つを渡す（ここで信頼を得る）
5. **（3分）** ヒアリング（下記）
6. **（2分）** 提案：「この3か月、モニターとして一緒にやりませんか」

## 3. ヒアリング項目

- 今、新規のお客様は何を見て来店していることが多いですか？（食べログ／Googleマップ／Instagram／通りがかり／紹介）
- 増やしたいお客様は？（一人客／カップル／少人数グループ／貸切）
- 曜日・時間帯で空きやすいのは？
- 定休日・ラストオーダー・席数の正しい情報は？
- 国立野菜の仕入れ先（農家名を出してよいか）
- 予算の目安（お一人様の平均）
- 公式サイトは誰が更新していますか？（食べログの公式HPサービスか、編集権限はあるか）
- Googleマップのオーナー確認は済んでいますか？
- 集客に毎月使っている費用は？（食べログ有料プラン等）

## 4. 料金提案

最初の1店舗は、**事例づくりを優先したモニター価格**で提案する。

| プラン | 内容 | 料金（税別） |
|---|---|---|
| **モニタープラン（3か月）** ※推奨 | 下記「毎月の作業」すべて＋開始時の情報整備一式。事例として店名を出してよいことが条件 | 初期費用 0円／**月額 14,800円** |
| 通常プラン | 同上 | 初期費用 30,000円／月額 29,800円 |

**開始時の情報整備（初月）**
- 定休日・営業時間・席数・店名表記の統一（公式・食べログ・Googleマップ・Instagram・地域メディアへの訂正依頼）
- Googleマップのお店情報の整備（説明文・メニュー・写真・特徴）
- 公式サイトへの文字で読めるメニュー、「こんな方におすすめ」、よくある質問の追加（店主確認のうえ）
- 構造化データの設置（サイトの仕組み上可能な場合）

**毎月の作業**
- ChatGPT・Gemini での推薦状況の測定（10〜15問 × 各3回）と競合比較
- 季節料理などのお知らせの公式サイト掲載（月2回まで）
- 1ページの月次レポート（どの質問で紹介されたか／されなかったか、次の打ち手）

**お約束しないこと**：AI検索での紹介・順位、来店数の増加。
**解約**：モニター期間終了後はいつでも解約可。

## 5. よくある反論と答え

| 反論 | 答え方 |
|---|---|
| 「食べログに払ってるから十分」 | 食べログはこれからも大事です。今回もAIは食べログを参考にエソラさんを紹介していました。ただ、食べログ以外の情報（Googleマップ、公式サイト）が食い違っていると誤案内につながります。食べログを活かすための整備です |
| 「AIで店を探す人なんているの？」 | その場でスマホで質問して見せる。「まだ多数派ではないですが、増えていく今のうちに正しい情報を整えておくのが安上がりです」 |
| 「効果が出るか分からない」 | 保証はできません。だからこそモニター価格で、毎月同じ質問で測って数字でお見せします。変化がなければ3か月で止めていただいて構いません |
| 「自分でできそう」 | 無料でできる3つはこの場でお伝えしました。残りは毎月の測定と更新作業なので、営業しながらだと手が回らない部分をお引き受けします |
| 「お金に余裕がない」 | まずは無料の3つだけ試してください。1か月後にもう一度測定して、結果だけお届けします（→ 1か月後の再訪問の約束を取る） |

## 6. 契約後〜1か月のスケジュール

| 時期 | 作業 |
|---|---|
| 1日目 | ヒアリング30分、各アカウントの権限確認 |
| 1週目 | 営業情報の統一、Googleマップ整備、いいね！国立へ訂正依頼 |
| 2〜3週目 | 公式サイトにメニュー・FAQ・こだわり掲載、構造化データ設置 |
| 4週目 | ChatGPT・Gemini で測定（改善前の数値は契約直後に取得しておく）、月次レポート |
