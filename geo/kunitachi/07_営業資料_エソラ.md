- [ ] 診断レポートの「連絡先」を記入し、A4で2部印刷（[診断レポート](./06_無料GEO診断レポート_エソラ.md)）

- [ ] 名刺／連絡先カード

## 1. 最初の接触（Instagram DM／電話／会計時）

**Instagram DM 文面**

> 突然のご連絡失礼いたします。国立で飲食店さま向けに「AI検索」の調査をしている〇〇と申します。
> 最近ChatGPTなどのAIで「国立で焼き鳥がおいしい店は？」と調べる方が増えており、国立駅周辺の居酒屋さんがAIでどう紹介されているかを調べています。
> エソラさんは「一人飲み」の質問で1番目に紹介されていた一方、「地元野菜」「デート」などの質問では名前が挙がっていませんでした。また、定休日がサイトによって「日曜」「不定休」と違って掲載されている点も見つかりました。
> 調査結果をA4数枚の無料レポートにまとめましたので、10分ほどお時間をいただけましたらお渡しして説明いたします。営業時間外のご都合のよい時間を教えていただけますと幸いです。

**電話・対面での一言（30秒）**

> 国立の飲食店さんがChatGPTみたいなAIでどう紹介されているかを調べている者です。エソラさんについて無料で診断したら、定休日の情報が食い違っているところなど、いくつか直したほうがいい点が見つかりました。レポートをお渡しして10分だけ説明させていただけませんか。売り込みではなく、まずは結果をお伝えしたいです。

## 2. 診断レポート説明の流れ（10〜15分）

1. **（1分）** AIで店を探す人が増えている話。スマホでその場でChatGPTに質問して見せる
2. **（3分）** 結果：「ChatGPTはデートの質問で1番目にエソラさんを紹介しました。でも一人飲みでは、えにし家が3回とも紹介され、エソラさんは0回。理由は公式サイトに『一人飲み』と書いていないからです」
3. **（4分）** 課題：定休日の不一致 → 「日曜にAIが『営業中』と案内する可能性」。メニューがAIに見えていない。店名の読み
4. **（2分）** 今すぐできる無料の3つを渡す（ここで信頼を得る）
5. **（3分）** ヒアリング（下記）
6. **（2分）** 費用対効果（レポート5章）：「最初の整備と3か月のサポートは無料です。その後続ける場合、ライト（月4,980円）なら客単価4,000円で**月2人**増えれば元が取れます。実際の客単価と原価率を教えていただければ、この場で計算し直します」
7. **（1分）** 提案：「実績づくりのため、先着10店だけ、最初の整備と3か月のサポートを無料でやっています。一緒にやりませんか。条件は、結果を事例として紹介させていただくことと、新しいお客様にどこで知ったか聞いていただくことだけです。3か月後に続けるかどうかは自由で、縛りもありません」

## 3. ヒアリング項目

- 今、新規のお客様は何を見て来店していることが多いですか？（食べログ／Googleマップ／Instagram／通りがかり／紹介）
- 増やしたいお客様は？（一人客／カップル／少人数グループ／貸切）
- 曜日・時間帯で空きやすいのは？
- 定休日・ラストオーダー・席数の正しい情報は？
- 国立野菜の仕入れ先（農家名を出してよいか）
- 予算の目安（お一人様の平均）
- 公式サイトは誰が更新していますか？（食べログの公式HPサービスか、編集権限はあるか）
- Googleマップのオーナー確認は済んでいますか？
- 集客に毎月使っている費用は？（食べログ有料プラン等）
- **実際の客単価と原価率**（レポート5章の試算を差し替えるため）
- 新規のお客様は月に何人くらいか、増やせる余裕のある曜日・席はあるか

## 4. 料金提案

**方針：最初の整備で効果の大部分を出し、その後は安い月額・縛りなしで「代わりに更新する人」になる。** ツールの機能でLOCALGOAT等と競わない（[09](./09_競合調査と料金設計.md)）。

| メニュー | 内容 | 料金（税別） |
|---|---|---|
| **初期整備パック** | 下記「初期整備」すべて＋1か月後の再測定レポート | **39,800円**（1回のみ） |
| **月額サポート ライト** | 下記「毎月の作業」のライト分 | **月4,980円**・**縛りなし**（いつでも解約） |
| **月額サポート スタンダード** | 下記「毎月の作業」すべて | **月9,800円**・**縛りなし**（いつでも解約） |
| **無料モニター（先着10店）** | 初期整備パック＋スタンダード3か月分 | **0円**。3か月で自動終了し、自動で有料にはならない |

モニター終了後に続ける場合は、ライトかスタンダードを選んでもらう。初期整備パックの費用はかからない。多くの店はライトを選ぶ想定で、**利益の柱は初期整備パック**。

**無料モニターの条件**（ヒアリングシート5章で確認・チェックをもらう）
- 店名と結果（推薦率の変化など）を事例として紹介してよい
- 新規客に「どこで当店を知りましたか」を聞き、月末に件数を共有する（効果測定の根拠になる）
- 月1回・15分の振り返り
- 3か月後に感想（推薦コメント）をもらう

**無料にする理由（自分用メモ）**：事例と数字を集めて、11店目以降の有料営業で見せるため。特に「整備直後・1か月後・3か月後」の推薦率の推移は、買い切りでも効果が残るのか、継続が必要なのかを示す自分だけのデータになる。

**初期整備（初月）**
- 定休日・営業時間・席数・店名表記を主要媒体でそろえる（公式サイト・Googleマップ・食べログ・Appleマップ・Bingマップ・Instagram、掲載があればホットペッパー・Retty。地域メディアへは訂正依頼）
- Googleマップのお店情報の整備（説明文・メニュー・写真・特徴）
- 店主ヒアリングをもとに、公式サイトへ「こんな方におすすめ」「よくある質問」「こだわり」、文字で読めるメニューを掲載（店主確認のうえ）
- 構造化データの設置（サイトの仕組み上可能な場合）
- 1か月後にChatGPT・Geminiで再測定し、整備前と比べたレポートを渡す

**毎月の作業（月額サポート）**

| 作業 | ライト（月4,980円） | スタンダード（月9,800円） |
|---|---|---|
| AI測定と1枚の月次レポート | 簡易（15問×1回）。3か月ごとに詳しい測定 | 毎月詳しく（15問×3回）＋競合比較 |
| 営業時間・定休日・メニュー変更の代行（主要媒体をまとめて修正） | 月2回まで | 回数制限なし（常識の範囲） |
| 季節料理などのお知らせを公式サイトに掲載 | 月1回 | 月2回 |
| 口コミへの返信文案（返信は店主名義） | — | ○ |

**お約束しないこと**：AI検索での紹介・順位、来店数の増加。
**解約**：月額サポートはいつでも解約可（最低契約期間なし）。

**自分側の費用と時間の目安**
- 測定のAPI代（実績：1回答約30円、ChatGPTのみ）：ライト 月約500〜800円、スタンダード 月約1,400円。Geminiも測る場合はその分が加わる
- 作業時間（仮定）：初期整備 1店6〜8時間、ライト 1店月30〜45分、スタンダード 1店月1〜2時間
- 手残りの目安：ライト 約4,200円（時給 約5,600〜8,400円）、スタンダード 約8,400円
- 無料モニター10店の自己負担：API代 約4万円（3か月）＋作業時間。2〜3店ずつ時期をずらして始める
- 売上の目安：ライト40店＋スタンダード10店で月約30万円（199,200円＋98,000円）。これに新規の初期整備パックが加わる。11店目以降の営業が鍵

## 5. よくある反論と答え

| 反論 | 答え方 |
|---|---|
| 「食べログに払ってるから十分」 | 食べログはこれからも大事です。今回もAIは食べログを参考にエソラさんを紹介していました。ただ、食べログ以外の情報（Googleマップ、公式サイト）が食い違っていると誤案内につながります。食べログを活かすための整備です |
| 「AIで店を探す人なんているの？」 | その場でスマホで質問して見せる。「まだ多数派ではないですが、増えていく今のうちに正しい情報を整えておくのが安上がりです」 |
| 「効果が出るか分からない」 | 保証はできません。だからこそ最初の整備と3か月は無料で、同じ質問で測って数字でお見せします。変化がなければそのまま終了で構いません |
| 「他の業者には月3万円・半年契約と言われた」 | ツールを使いこなせるお店にはそれも良いと思います。私は、お店に代わって文章を書いて更新する係です。月4,980円から、いつでもやめられます |
| 「110媒体に配信、みたいなサービスもあるけど」 | お客様が実際に見ているのは、Google・食べログ・Instagramなど数か所です。そこを私が責任を持って正しく保ちます |
| 「無料って、後で高額請求されない？」 | 自動で有料になることはありません。3か月後に結果を見ていただいて、続けるかどうかを決めていただきます。ヒアリングシートにもそう書いてあります |
| 「自分でできそう」 | 無料でできる3つはこの場でお伝えしました。残りは毎月の測定と更新作業なので、営業しながらだと手が回らない部分をお引き受けします |
| 「手間がかかりそう」 | お店側の作業は、最初の30分のヒアリングと、月1回15分の振り返りだけです。営業時間が変わったらLINE等で一言いただければ、サイトやGoogleマップはこちらで直します |
