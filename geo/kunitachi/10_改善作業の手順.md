# 10 改善作業の手順（エソラを例に）

改善とは「AIが読む場所に、正しくて具体的な文章を置くこと」。ChatGPTは店の公式サイト・Googleマップ・食べログなどを読んで推薦理由を作っている（08）。だから、そこに書いてある内容を直す・足すのが作業の中心になる。

## 0. 事前準備：権限をもらう（パスワードは預からない）

| 場所 | 権限のもらい方 | 店主の手間 |
|---|---|---|
| Googleマップ（Googleビジネスプロフィール） | 店主がプロフィールの「ユーザー（ビジネス情報の管理権限）」にあなたのGoogleアカウントを「管理者」で招待する | 5分 |
| 公式サイト（エソラは食べログの公式HPサービスと思われる） | 食べログ店舗会員の管理画面で編集する。**サブアカウントや担当者追加ができるかは要確認**。できなければ、店主と画面を一緒に見ながら作業する | 要確認 |
| 食べログの店舗情報 | 同上（店舗会員の管理画面） | 要確認 |
| Appleマップ（Apple Business Connect） | あなたのApple IDで店舗の管理を申請し、店主の電話で確認を受ける | 5分 |
| Bingマップ（Bing Places） | Googleビジネスプロフィールから情報を取り込む | 0分 |
| Instagram | プロフィール欄は店主に文面を渡して直してもらう | 5分 |

ヒアリング（30分）のときに、この表を見せながらその場で招待してもらうのが一番早い。

## 1. 営業情報をそろえる（1〜2時間）

1. ヒアリングで正しい定休日・営業時間・L.O.・席数を確定する（例：定休日は日曜、料理L.O.は22:00か22:30か）
2. 下の場所を順番に開き、同じ内容に書き換える

| 場所 | 直す項目（エソラの例） |
|---|---|
| 公式サイトの店舗情報 | 店名欄「エソラ」→「串と〆シ（くしとメシ）エソラ」、L.O.、席数 |
| Googleマップ | 営業時間、定休日、祝日の営業時間 |
| 食べログ | 定休日（「不定休」と出ていないか）、L.O. |
| Appleマップ・Bingマップ | 営業時間、定休日 |
| Instagramのプロフィール | 「定休日：日曜」「串と〆シ（くしとメシ）」を追記 |
| いいね！国立（地域サイト） | 記事の「不定休」を問い合わせフォームから訂正依頼 |

## 2. 公式サイトに文章を足す（2〜3時間）

**ここが一番効く。** 今回、えにし家が「一人飲み」で3回中3回推薦されたのは、公式サイトに「カウンターは1人飲みに」と書いてあったから。

1. ヒアリングで「増やしたいお客様」「看板料理」「仕入れ先」「店主の想い」を聞く
2. `05_改善施策_優先順位.md` の文案を、聞いた内容で仕上げる
   - **こんな方におすすめ**：一人飲み（カウンター9席・一杯だけでも歓迎）／デート（地下の落ち着いた空間）／少人数（4名テーブル2卓）／〆まで食べたい方
   - **よくある質問**：定休日、一人で入れるか、国立野菜の使い方、鶏の産地、予算、予約方法
   - **こだわり**：つくね（部位のブレンド・青梅の卵）、国立の農家さんの野菜、2週間ごとの季節料理
3. 店主に文章を確認してもらう（LINEで送って「OK」をもらう程度）
4. 公式サイトの「こだわり」ページ等の本文に貼り付ける

**エソラ固有の注意**：公式サイトは食べログの公式HPサービスと見られ、メニューはプログラムで表示される仕組み（AIには見えていない）。
- 管理画面で**文章を書ける欄**（こだわり・お店のPR等）があれば、そこに上の文章とメニューの主な品目・価格を文字で書く
- ページの追加や構造化データの設置ができない場合は、**無理にしない**。文章の追加だけでも効果の大部分は見込める
- 管理画面で何ができるかは、契約後に最初に確認する（ここは現時点で未確認）

## 3. Googleマップを整える（1時間）

| 項目 | やること |
|---|---|
| ビジネスの説明 | `05` の説明文案（750文字以内）を貼る |
| カテゴリ | メイン「焼き鳥店」、追加「居酒屋」 |
| メニュー | 主な串・〆・飲み物を価格つきで登録 |
| 写真 | 外観（地下への階段の入口がわかるもの）、カウンター、つくね、〆、SORACHIの生ビール。店主のスマホから10枚ほどもらう |
| 属性 | 「一人客歓迎」「カウンター席」「禁煙」など、当てはまるものに印をつける |

## 4. 効果を確かめる（1か月後、30分）

1. 整備前と同じ10問をChatGPTに聞く（`measure_api.py` で自動化済み）
2. `tally.py` で推薦率を出し、整備前と比べる
3. 1枚のレポートにして店主に渡す（「一人飲み：0回→○回」など）

## 毎月の作業（ライト／スタンダード）

- 店主から「来週の月曜は臨時休業」「新しい季節料理」などの連絡をLINEでもらう
- 上の1・2で触った場所を同じ内容に直す（10〜20分）
- 月1回、測定してレポートを送る

## 作業時間の合計（初期整備）

ヒアリング30分＋営業情報1〜2時間＋文章作成2〜3時間＋Googleマップ1時間＋確認やり取り ≒ **5〜7時間**
