# zaito Design System v1

LP・求人サイト・企業向け画面・仮ページ・SNSクリエイティブ・営業資料で、見た目と使いやすさをそろえるための共通ルール。
構成はデジタル庁デザインシステムの考え方（原則 → 基礎 → 部品 → パターン → アクセシビリティ → 文章）を参考にし、
**値はすべて、Claude Designで作った今のLP（`wordpress-theme/zaito/lp/zaito-lp.dc.html`）で実際に使っているもの**に合わせている。

- CSSで使うときは `wordpress-theme/zaito/lp/tokens.css` の変数（`var(--z-blue)` など）を使う。色コードを直接書かない。
- 迷ったときの優先順位：**分かりやすいか > 信頼できるか > 操作しやすいか > zaitoらしいか > かっこいいか**

---

## 1. 原則

| 原則 | 意味 |
|---|---|
| Clear | 一目で意味が分かる。職種・働き方・報酬が3秒で分かる |
| Calm | 派手にせず、安心して使える。白が基本、青は差し色 |
| Accessible | 誰でも読めて操作できる（→ 9. アクセシビリティ） |
| Young, not childish | 若者向けだが、幼くしない |
| Honest | 誇張しない。煽らない。副業商材っぽくしない |

---

## 3. 文字

- 日本語：**Noto Sans JP**（400 / 500 / 700 / 900）
- 英数字・ロゴ・大きな数字：**Outfit**（500 / 600 / 700）
- アイコン：**Material Symbols Rounded**
- 和文の詰め：`font-feature-settings: 'palt'`

| 役割 | サイズ | 太さ | 行間 |
|---|---|---|---|
| ヒーロー見出し | 38〜76px（画面幅で可変） | 900 | 1.22 |
| ページ見出し（H1） | 24〜40px（可変） | 900 | 1.3〜1.4 |
| セクション見出し（H2） | 24〜32px（可変） | 900 | 1.35 |
| 小見出し（H3） | 18〜20px | 700 | 1.5 |
| 本文（大） | 16〜18px | 400 | 1.75 |
| 本文 | 15〜16px | 400 | 1.75 |
| 補足 | 13〜14px | 400〜500 | 1.7 |
| 注記 | 12px | 400 | 1.7 |

- スマホの本文は **16px以上**（15pxは補足まで）
- 報酬などの大きな数字は Outfit で 22〜36px

---

## 4. 余白・レイアウト

- 余白は 4 / 8 / 12 / 16 / 20 / 24 / 28 / 32 / 40 / 48 / 56 / 64 / 80 / 96 / 112px から選ぶ
- コンテンツ最大幅 **1240px**（左右20pxの余白込み）、読み物ページの本文幅 **760px**
- ヘッダーの高さ **68px**（sticky、白92%＋ぼかし、下に1pxの区切り線）
- ブレイクポイント：スマホ 〜640px ／ タブレット 641〜860px（ここで1カラムに切り替え）／ PC 861px〜
- 幅1440pxを超えるPCでは、LPはページ全体を拡大して左右の余白を広げすぎない（最大1.5倍）

---

## 5. 角丸・影

| 用途 | 変数 | 値 |
|---|---|---|
| 小さいバッジ | `--z-r-sm` | 8px |
| ボタン・入力欄（基本） | `--z-r-md` | 12px（ヘッダー内の小さいボタンは10px） |
| カード | `--z-r-lg` | 16px |
| 大きい面・画像 | `--z-r-xl` | 20px |
| チップ・タグ | `--z-r-pill` | 999px |

| 影 | 変数 | 使う場所 |
|---|---|---|
| 弱 | `--z-shadow-sm` | カードのホバー |
| 中 | `--z-shadow-md` | 応募ボックスなど、1画面に1つの重要な面だけ |
| CTA | `--z-shadow-cta` | 青いメインボタンのホバー |
| フォーカス | `--z-focus-ring` | 入力欄・ボタンのフォーカス時 |

影は基本的に弱く。枠線（1〜1.5px）で区切るのを優先する。

## 6. 部品（Components）

### ボタン
| 種類 | 見た目 | 高さ |
|---|---|---|
| Primary | 青背景・白文字・太字700 | 56〜60px（ページ内）／44px（ヘッダー） |
| Secondary | 白背景・`--z-border-input` の1.5px枠・紺文字 | 同上 |
| Text | 背景なし・青文字・太字 | — |

- 状態：通常 / ホバー（`--z-blue-hover`、1px持ち上げ）/ フォーカス（`--z-focus-ring`）/ 無効（薄くしてカーソル通常）/ 送信中（文言を「送信中…」に）
- タップ領域は **44px以上**
- 文言は動詞で短く：「先行登録する」「求人を見る」「無料で掲載する」「応募する」

### 入力欄
- 高さ54〜60px、角丸12px、`--z-border-input` の1.5px枠、左右16pxの内側余白
- フォーカス：枠を青に＋`--z-focus-ring`
- エラー：枠を `--z-error` にし、**必ず下にエラー文を出す**（色だけで伝えない）。`aria-invalid` を付ける
- **ラベルは入力欄の上に置く**。プレースホルダーは入力例だけ（ラベルの代わりにしない）
- 必須・任意は、ラベル横の小さなバッジで示す

### タグ・チップ
- カテゴリ：薄い青背景＋青文字（例「SNS運用」）
- 条件タグ：`--z-chip` 背景＋`--z-text-2`（例「完全在宅」「学生歓迎」「週10時間〜」）
- 新着：紺背景＋白の「NEW」（Outfit）
- 1枚のカードでタグは **3つまで**

### 求人カード
表示順：写真またはアイコンタイル → カテゴリ（＋NEW）→ 職種名 → 会社名 → 条件タグ（3つまで）→ 報酬（Outfitの大きな数字）
- 角丸16px、`--z-border` の1px枠、影なし（ホバーで `--z-shadow-sm`）
- 避ける：タグ5個以上、アイコンの並べすぎ、強い影、派手なロゴ、情報の詰め込み

### ヘッダー
左にロゴ「zaito」（Outfit 700、iだけ青）。中央に「求人を探す／企業の方／zaitoについて」。右にテキストボタン＋青いCTA 1つ。スマホではメニューボタン＋CTA。

### 求人詳細（仮ページで実装済み：`lp/job-preview.php`）
画像 → カテゴリ → 職種名 → 会社 → 4つの条件（報酬・勤務形態・勤務日数・雇用形態）→ 仕事内容 → 歓迎する人 → 応募の流れ。
PCは右に応募ボックス（追従）、スマホは画面下に報酬＋応募ボタンを固定。

## 7. 画面パターン

- **先行登録**：最初はメールアドレスだけ。登録後に任意で「興味のある仕事」。完了メッセージは「先行登録ありがとうございます」。
- **ワーカー本登録**：必須（メール・パスワード）と任意（大学名・学年・学部）を分ける。興味・スキル・稼働可能時間は登録後のプロフィールで。
- **企業の求人掲載**：会社名・職種・仕事内容・報酬・稼働時間・完全在宅か・学生の応募可否・必須スキル・歓迎スキル。
- **空の状態**：「求人がありません」で終わらせず、「この条件に合う求人は今ありません。条件を広げるか、新着のお知らせに登録してください」と次の行動を示す。
- **読み込み中**：スピナーだけでなく、カードの形をした仮表示（スケルトン）を優先。
- **エラー**：人が読んで分かる言葉で。「読み込みに失敗しました。時間をおいてもう一度お試しください。」
- **ポップアップ**：強制的に出すポップアップは使わない。LPの下部の先行登録案内のように、閉じられて、一度閉じたら出さない形にする。

---

## 8. 画像・動き

画像の優先順位：①実際のサービス画面 ②作業環境の実写 ③実在の学生・企業の写真 ④シンプルな図形。**AIで作った人物画像は使わない。**

動き：フェード、8〜16pxのスライド、0.15〜0.25秒の変化まで。バウンド・3D回転・常に浮遊する動き・大きなパララックスは使わない。`prefers-reduced-motion` のときは動きを止める。

---

## 9. アクセシビリティ（最低限守ること）

- 文字と背景のコントラスト **4.5以上**（大きな見出しは3以上）。上の色表の数値を参照
- キーボードで操作でき、フォーカス表示を消さない
- 入力欄には必ず `label` を付ける
- 画像には `alt`（飾りの画像は `alt=""`）
- 色だけで状態を伝えない（エラーは文字でも）
- タップ領域は44px以上、スマホの本文は16px以上
- 「本文へスキップ」リンクを置く（LPは実装済み）

既知の例外：LPの「01〜04」の飾り数字は `#8A93AB`（3.07）。本文ではないので許容しているが、新しい画面では `--z-text-4` 以上の濃さを使う。

---

## 10. 文章（Content）

- 短く、はっきり、具体的に。煽らない
- 学生向け：親しみやすいが、軽すぎない
- 企業向け：簡潔・誠実・筋道立てて
- 良いCTA：「先行登録する」「求人を見る」「無料で掲載する」「応募する」
- 使わない：「今すぐ人生を変える」「稼げる」「チャンスを掴む」など

---

## 11. SNSクリエイティブ

- 背景は白か薄いグレー、文字は紺、差し色に青
- 1画面に1メッセージ、字幕は太字
- 求人紹介の型：「完全在宅」→ 職種名 → 報酬（大きく）→「学生歓迎」→「詳しくはプロフィールから」

---

## 12. Do / Don't

| Do | Don't |
|---|---|
| 広い余白 | グラデーションの多用 |
| はっきりした見出しの階層 | カードの乱立・斜めに並べたカード |
| 少ない色 | アイコンの並べすぎ |
| 枠線で区切るシンプルなUI | ガラス風（すりガラス）・3D風のUI |
| 実際の情報を中心に | AI SaaSのテンプレっぽさ・副業商材っぽさ |
